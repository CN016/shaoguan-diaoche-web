## 技术架构

- **Node.js + Express 动态渲染**：模板只存一份，用户访问 `城市.016.wiki` 时按域名实时渲染页面（首页 / 13 个频道 / 977 篇文章 / 分页 / sitemap / robots）；
- **缓存自适应小内存服务器**：内存 LRU 设上限（默认 2000 页）+ 磁盘缓存回源，数据变化后重启自动清缓存；
- **SEO 内置**：每站唯一 title/description/keywords、canonical、Open Graph、LocalBusiness + Article + Breadcrumb 结构化数据、动态 sitemap（lastmod 为访问日前一天）、10 个文章频道全量分页；
- **号码清洗**：渲染层统一清洗号码与品牌字眼，保证全站只出现真实联系方式；
- **扩展文章**：模板化批量生成 FAQ / 新闻 / 服务项目 / 案例 / 车型文章，语料与重写结果可插拔。
